# Crates

One line per crate: what it owns. A new crate arrives only when its first real caller does (sensors, advisories and notifications come next).

| Crate | Owns |
|---|---|
| `guard-dog` | The `guard-dog` binary: the command line, and later the daemon and the local status page. It holds no logic of its own; that lives in the library crates. `--version` names the release, plus the exact git commit for release builds (which set `GD_GIT_COMMIT`); local builds say "development build". |
| `gd-core` | The shared types. `Untrusted<T>` is outside text as a type the compiler tracks: it can't be printed, compared or passed on except through `escape_for_terminal()`, `escape_for_html()` or a greppable `expose_untrusted()`, and every use of the last one needs a reviewer's OK. `Fact`, `Finding` and `Advisory` are placeholders until the inventory and the matcher are built. |
| `gd-egress` | Judge C's tooling: makes the planted canary secrets and checks an egress capture against `allowlist.toml`, decoding gzip, deflate and brotli request bodies before it scans them. Test tooling only; never in a release. |
| `gd-notify` | Alerts as private Nostr direct messages (NIP-17), to the regtest lab's own relay only (`ws://strfry:7777` and the other lab host names, which must resolve only to the lab's own subnet, 172.29.208.0/24; anything else is refused; the 10 second limit covers the whole conversation, even a relay that sends one byte at a time). Builds NIP-44 v2 encryption, the NIP-59 seal and gift wrap, and BIP-340 signatures from RustCrypto parts (the `nostr` crate needs libsecp256k1, which `deny.toml` refuses). Guard Dog's own key lives in `<state dir>/notify.key` (0600, folder and file both owned by the user running Guard Dog, removed if its write fails; secret values are wiped from memory when dropped, best effort: copies the compiler or the operating system make cannot be reached), never the user's `nsec`. Turns an `Alert` of validated values into one plain-text message, with outside text escaped, capped and quoted; sends only critical, high or unknown-severity findings, at most 20 messages per run plus one summary that says how many findings were not sent and why (over the cap, medium or low, or on another chain); and sends nothing unless the node's chain is regtest or signet (a single alert on another chain is dropped and counted, never sent). A recipient is an npub only. Time and randomness come in through injected sources. |

Rules that hold in every crate: no `unsafe` (the workspace forbids it), no network access outside the allowlist, no shell commands built from outside text, and the core works with no AI model.
