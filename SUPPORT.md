# Getting help with Guard Dog

Guard Dog is pre-alpha and run by one maintainer, me, in the open. Here's where to go so your question gets answered and helps the next person too.

| You want to… | Go to |
|---|---|
| Ask how something works, or get help with your setup | [Discussions: Q&A](https://github.com/MaxSikorski/guard-dog/discussions/categories/q-a) |
| Share an idea, or answer a roadmap open question | [Discussions: Ideas](https://github.com/MaxSikorski/guard-dog/discussions/categories/ideas) |
| Talk about a node platform (Umbrel, StartOS, RaspiBlitz, myNode, nix-bitcoin) | [Discussions: Node platforms](https://github.com/MaxSikorski/guard-dog/discussions/categories/node-platforms) |
| Report a bug, a false alarm or a missed advisory | [Open an issue](https://github.com/MaxSikorski/guard-dog/issues/new/choose) and pick the matching form |
| Add your project to the catalog | The "Add my project" form, and [CONTRIBUTING.md](CONTRIBUTING.md#add-my-project) |
| Report a vulnerability in Guard Dog | **Privately**, never in public: [SECURITY.md](SECURITY.md) |
| Report a vulnerability in something Guard Dog watches | That project's own security contact first |
| Report a Code of Conduct problem | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#enforcement) |

## Before you post

- **Never post secrets.** No seed phrases, nsecs, xpubs, macaroons, passwords, tokens, IP addresses, onion addresses or hostnames. Redact logs and screenshots first. Nobody from this project will ever ask you for a seed, an nsec or a password. If someone does, it's a scam.
- **Search first.** Your question may already have an answer in Discussions or the issues.
- **Say what you run.** The platform, the services and their versions make most questions answerable on the first reply.

## What to expect

I read everything, but I'm one person, so answers can take a few days. Security reports get a reply within 7 days, as [SECURITY.md](SECURITY.md) says. There's no paid support and no private support channel.

Guard Dog says "no known issues found", never "secure". It helps you keep watch; it doesn't replace your own judgment.
